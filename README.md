# 40ka

Сайт студии брендинга 40ka. Статический: index.html, cases/, assets/, img/.

## Английская версия

`en/` — английские копии страниц. Источник — русские страницы: после правки русского текста
добавьте его английский вариант в `TR` в `tools/build_en.py` и запустите `python3 tools/build_en.py`.
Скрипт сам покажет, для каких текстов ещё нет перевода.
